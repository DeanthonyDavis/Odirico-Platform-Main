# Odirico brand asset status

**October 5, 2026:** The public corporate website now uses a typographic **ŌDIRICO** display wordmark in locally bundled Geist. `odirico-display-profile.png`, `../images/odirico-ownership-social.png`, and `../icons/odirico-macron*` are the new public assets, generated by `scripts/prepare-ownership-assets.mjs`. The following earlier artwork is retained for legacy use and is no longer rendered by the public site. Private applications and the shared brand package are unaffected.

These assets are **provisional reconstructions from the supplied flat JPEG artwork**, not original production vectors. The custom ODIRICO letters and HOLDINGS subtitle are paths extracted from the clean top-left panel. The circular symbol uses the flat ICON panel and preserves both upper-right interruptions. No photographic mockup was traced and no font was substituted.

- `odirico-black.svg`, `odirico-white.svg`: full lockup, transparent background.
- `symbol-black.svg`, `symbol-white.svg`: standalone symbol, transparent background.
- `social-profile.png`: 512×512 opaque white profile image.
- `../icons/favicon.svg` and `../icons/favicon-32.png`: favicon assets.
- `../icons/apple-touch-icon.png`: 180×180 opaque Apple touch icon.
- `branding-metadata.json`: source resolution and exact extraction crop coordinates.

Original vector artwork is requested for final geometry and spacing verification before public launch. Source reference and enlarged visual review exports are in `docs/sources`, outside the publicly served directory.
